Nueva predicción de rutina

Método automático: con peso, altura, edad y duración se aplica la regresión lineal múltiple entrenada desde el CSV. Si falta altura o edad, se conserva el respaldo Keytel (FC/edad/sexo) o MET × peso × duración.

El peso, edad y sexo se toman de tu perfil. Si cambias el peso aquí abajo, se guarda antes de calcular.
¿Cómo se hace el cálculo?

Regresión (principal): Ŷ = β0 + β1X1 + β2X2 + β3X3 + β4X4, con β = (XᵀX)⁻¹ XᵀY entrenado desde data/dataset_calorias.csv. X1 = peso, X2 = altura, X3 = edad, X4 = minutos. Ver el desglose completo en Análisis técnico más abajo.

MET (respaldo): calorías = MET × peso_kg × (duración_min / 60). Ejemplo: 8 MET × 70 kg × (30 / 60) h = 280 kcal.

Keytel: usa tu FC promedio, edad y sexo (M/F): ((-55.0969 + 0.6309·FC + 0.1988·peso + 0.2017·edad) / 4.184) × minutos para hombres; ((-20.4022 + 0.4472·FC - 0.1263·peso + 0.0740·edad) / 4.184) × minutos para mujeres.

Se aplica Keytel solo cuando hay FC promedio, edad y sexo M/F; en caso contrario se usa MET. Cada registro guardado incluye su desglose con la fórmula y los valores sustituidos. Resultado redondeado a 2 decimales; es una estimación educativa, no un diagnóstico.
